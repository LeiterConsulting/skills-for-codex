# Asset provenance

The skill instructions, input records, JSON schema, native app and release record helpers, tests and collection tools are original assets authored for this public collection and released under MIT.

The workflows draw on experience with Splunk app authoring and release qualification, and the linked official platform references. No private project source, installer/verifier implementations, customer records, workstation configuration, credentials, React starter, Splunk SDK implementation or proprietary game assets are included.

Generated app.conf, metadata and Simple XML use platform configuration formats. Compatibility depends on the chosen target and its current official requirements. External packages and starters used by a consumer remain subject to their own licenses and terms.

The collection's license and copyright identify its publisher. They are not defaults for generated app identity, authorship, branding or target access.
