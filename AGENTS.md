# Repository instructions

Maintain focused, portable skills and original reusable assets.

- Keep project identity, workspace paths, targets, endpoints, role names and template sources in documented inputs. An agent may discover or propose them from the user's project; record the choice.
- Keep credentials in the target's approved secret mechanism, outside skill assets and ordinary input records.
- Keep the public collection independent of private portfolio inventories and local project implementations.
- Link official domain references. Label structural, package, AppInspect, installed and live evidence separately.
- Preserve existing target applications. Scaffolding is an explicit operation for a new destination.
- Validate helper behavior with `python -m unittest discover -s tests -v` and collection structure with `python scripts/validate_collection.py`.
- Use Python 3.10+ standard library for public helpers unless a specific capability requires a documented dependency.
- Do not claim skill performance improvements without matched agent evaluations.
